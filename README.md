# Minimalist CV

## Edit Your Data

All resume content is located in a single file:
`src/data/resume-data.tsx`

---

## How to Use

1.  **Start the development server:**
    ```bash
    pnpm dev
    ```

2.  **Open the app:**
    Go to [http://localhost:3000](http://localhost:3000) in your browser.

3.  **Edit your data:**
    Modify the `src/data/resume-data.tsx` file. The browser will auto-refresh as you save changes.

4.  **Print or Save as PDF:**
    Press `Cmd + P` (Mac) or `Ctrl + P` (Windows) to open the print dialog and save your CV as a PDF.
